## Purpose
讓玩家在桌面與窄視窗中看到一致的順時針正常出牌方向，以玩家下方為起點依序經過左側、上方與右側；同時保留既有座位身分與吃碰槓回應規則，避免視覺調整改變遊戲邏輯。
## ADDED Requirements
### Requirement: 順時針座位
UI SHALL 將東家置下、南家置左、西家置上、北家置右，包含窄視窗；引擎 SHALL 保持東南西北輪序與吃碰槓來源限制。
#### Scenario: 正常回合
- **WHEN** 依東南西北輪流出牌
- **THEN** 行動座位依下、左、上、右呈現
#### Scenario: 回應插入
- **WHEN** 其他玩家取得吃碰槓或胡牌回應權
- **THEN** 行動框跟隨該玩家實際座位，而非強制跳至下一位置
#### Scenario: 窄視窗
- **WHEN** 於 390×844 或 800×600 開啟牌桌
- **THEN** 保持座位相對位置、控制可達且無水平溢出
