## Purpose

將麻將遊戲交付為可在目前 macOS 電腦獨立啟動的桌面應用，包含遊戲所需本機資源，支援離線遊玩與視窗生命週期，明確標示本機未簽章交付的限制。

## ADDED Requirements

### Requirement: 離線桌面交付
應用 SHALL 在開發伺服器停止時使用內附資源啟動，支援縮放、最小化、還原及退出；打包文件記錄平台、架構與簽章狀態。
#### Scenario: 打包後遊玩
- **WHEN** 在 macOS 啟動打包產物而不使用開發伺服器
- **THEN** 可開局、摸打、終局及再開局；退出不留下自行啟動的背景服務

### Requirement: 原生邊界
桌面頁面 SHALL 不具任意檔案或 shell 能力，拒絕非預期遠端導覽與原生權限請求。
#### Scenario: 不可信導覽
- **WHEN** 頁面要求非允許的導覽或新視窗
- **THEN** 不在遊戲的原生權限範圍載入該內容
