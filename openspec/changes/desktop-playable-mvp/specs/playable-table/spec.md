## Purpose

提供可實際操作的四方麻將牌桌，讓玩家清楚辨認當前回合與可用動作，透過選牌確認、胡牌回應及結算控制完成單局，並在鍵盤與小視窗下保持操作可達。

## ADDED Requirements

### Requirement: 可見牌桌與操作
UI SHALL 顯示自己的手牌、對手牌背張數、各家花牌與牌河、剩餘牌數及行動者。點選手牌後確認出牌，使用唯一牌 ID，不在自己回合不得出牌，合法時提供胡／過或自摸。
#### Scenario: 選牌出牌
- **WHEN** 玩家選取一張手牌後確認出牌
- **THEN** 傳送該牌 ID 與當前 revision 一次，等待新狀態，不顯示吃碰槓
#### Scenario: 隱藏與終局
- **WHEN** 遊戲進行或結束
- **THEN** 進行中不揭露對手暗牌，結束時顯示理由與公開終局牌，提供再開一局

### Requirement: 設定與可用性
UI SHALL 提供模式、進階 seed 及重開；進行中重開須確認，可取消且保留牌局。鍵盤可選牌、出牌、胡／過。小視窗控制可達。
#### Scenario: 取消重開
- **WHEN** 玩家要求改規則重開但取消
- **THEN** 牌局與模式不變
#### Scenario: 鍵盤及小視窗
- **WHEN** 於 1280×800、800×600、390×844 操作牌桌
- **THEN** 焦點可見，控制不被遮擋，捲動可達所有動作
